# Instacart Market Basket Analysis

## Project Overview

This project analyzes Instacart’s grocery order data to understand customer purchase behavior, reorder patterns, basket composition, and product associations. The project combines exploratory data analysis (EDA), market basket analysis, and dashboarding to generate business insights that can support cross-selling, product placement, promotions, and recommendation strategies.

## Business Objective

The goal of this project is to analyze customer ordering behavior and identify products that are frequently purchased together. By studying order patterns, reorder behavior, basket size, and product affinity, the analysis aims to provide insights relevant to recommendation systems, category management, and promotional strategy.

## Dataset

This project uses the Instacart Market Basket Analysis dataset. The core files used are:

* orders.csv
* order_products__prior.csv
* order_products__train.csv
* products.csv
* aisles.csv
* departments.csv

## Planned Project Workflow

1. Data loading and schema understanding
2. Data quality checks and validation
3. Exploratory Data Analysis (EDA)
4. Basket size, reorder, and customer behavior analysis
5. Market Basket Analysis using association rules
6. Tableau dashboard creation
7. Final report and business recommendations
